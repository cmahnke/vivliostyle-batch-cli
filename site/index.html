vivliostyle-batch-cli

Batch-oriented HTML-to-PDF rendering on top of Vivliostyle and headless Chrome — canvas charts, WebGL scenes and cross-origin iframes end up in the PDF, sharp past 96dpi. 

npm install -g @projektemacher/vivliostyle-batch-cli
vivliostyle-cli -i index.html -o output.pdf
